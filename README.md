# HSBC SME Assistant

This project is now a standalone HTML app.

## Run Locally

Open `app_presenter-console.html` directly in a browser if you want the standalone presenter control panel.

Open `app_account-opening.html`, `app_fx-hedging.html`, `app_mainland-branch.html`, `loks_account-opening.html`, or `vid_v1.html` to `vid_v4.html` directly if you want to view a standalone display page.

No build step, package manager, or local server is required.
