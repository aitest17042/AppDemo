# HSBC SME Assistant

This project is now a standalone HTML app.

## Run Locally

Open `presenter-console.html` directly in a browser if you want the standalone presenter control panel.

Open `account-opening.html`, `fx-hedging.html`, `mainland-branch.html`, `locked-screen.html`, or `v1.html` to `v4.html` directly if you want to view a standalone display page.

No build step, package manager, or local server is required.
